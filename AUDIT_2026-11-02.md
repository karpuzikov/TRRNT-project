# TRRNT-project audit and fixes - 2026-11-02

**TL;DR:** The Organizer's own test suite had never passed on v0.3.22 (9 failures), and its naming-table test was still loading v0.03.05. Both are now green against new versions. Unverified dependency downloads in all three tools are now pinned by SHA-256, the ALAC tool no longer deletes CUE album images it cannot verify, and the Analyzer's accent, Cyrillic and remaster-year title matching is fixed.

Scope: `main` @ `7286635` (2026-10-31), compared with the previous audit @ `91662df` ([AUDIT_2026-10-14.md](AUDIT_2026-10-14.md)). Static review plus Linux/Python 3.13 unit tests. **NOT RUN:** Windows GUI/WebView2, refalac64/flac/AudioChecker/fpcalc binaries, live MusicBrainz, real audio.

## Behavior changes to know about

- **Organizer:** `YO` is now written `Yo`, because RULES.md says all-caps styling alone is not an acronym. If `YO` is wanted, add it to `_PROTECTED_TITLE_NAMES`.
- **Analyzer:** accented and plain spellings now share one identity. Saved skip rules keyed on an old accented identity may need to be set again.
- **ALAC tool:** after converting a CUE release, delete the original image yourself once the ALAC tracks check out. A rerun on that folder stops with an explicit message instead of overwriting.
